Description:
A web-based system for collecting, storing, and managing census data. 
Features:
User registration and login (password hashing)
Role-based access (Commissioner, Deputy Commissioner, Supervisor, Census Officer)
Manage counties, subcounties, and wards
Household and person data entry
Reports and dashboard

Technologies:
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: Apache (XAMPP)
